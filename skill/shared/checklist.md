# 通用自检清单

## 通用基准（所有模板共享）

每张海报生成后，必须逐项核对以下 6 项。若任一项未通过，必须重绘。

| 序号 | 检查项 | 通用标准 |
|------|--------|---------|
| 1 | LOGO、二维码位置大小 | LOGO 和二维码位置固定，尺寸未变化 |
| 2 | 底部信息规范 | 无图标、小字体、紧凑行距、缩小二维码 |
| 3 | 无杂乱装饰 | 无多余网格、弧线、分割框 |
| 4 | 画风一致性 | 与模板规范完全一致，无突变 |
| 5 | 文字遮挡 | 文字未遮挡核心画面 |
| 6 | 色彩饱和度 | 符合模板要求的饱和度范围 |

## 各模板专属自检（补充项）

### 极素画册风
- [ ] 底部信息无色块边框
- [ ] 画风保持水墨画册风
- [ ] 色彩不过于艳丽

### 几何构成风
- [ ] 无渐变、阴影、弧线、圆角
- [ ] 插画无透视或写实细节
- [ ] 黑白强对比存在

### 暖光复古风
- [ ] 双层边框完整
- [ ] 做旧纸张质感/噪点存在
- [ ] 画风未偏向冷硬/水彩/写实

### 光影留白风
- [ ] 无全画面边框
- [ ] 主视觉为摄影质感（非插画）
- [ ] 色块介入存在且不鲜艳
- [ ] 留白充足（≥30%）
- [ ] 光斑锚点存在

### 静默人文风
- [ ] 无边框、色块介入、冷色叠加
- [ ] 主视觉含光影/树影方向性元素
- [ ] 标题为书法化宋体（飞白）
- [ ] 三段式细线分割存在
- [ ] 无渐变/投影/光泽等数字特效

### 科技流光风
- [ ] 主视觉为 3D 渲染质感（非插画/摄影）
- [ ] 粒子系统与光效存在
- [ ] 色彩不过于暖调
- [ ] 3D 图形偏左上（非居中）

### 新中式水墨风
- [ ] 竹枝破边元素存在
- [ ] 如意云头框存在
- [ ] 山水四层景深 + 空气透视
- [ ] 色彩无民俗化大红大绿
- [ ] 留白充足（≥40%）
- [ ] 标题为书法体（楷体/魏碑）

### 晨光纸艺风
- [ ] 色块三段分区清晰（深色顶 + 暖色中 + 浅色底）
- [ ] 纸张撕裂/毛边质感与噪点纹理存在
- [ ] 金色光源圆形 + 窗格阴影投射存在
- [ ] 压花/干燥植物标本元素存在（非鲜花/非水彩）
- [ ] 至少 2-3 层纸层叠贴，含胶带固定元素
- [ ] 无光滑渐变、数字光泽或弧线装饰（圆形光源除外）
