# 四季色系规则

## 季节自动判断

| 月份 | 季节 |
|------|------|
| 3-5 月 | 春 |
| 6-8 月 | 夏 |
| 9-11 月 | 秋 |
| 12-2 月 | 冬 |

## 各模板四季色系速查

### 极素画册风

| 季节 | 色系 |
|------|------|
| 春 | 浅豆绿、淡鹅黄 |
| 夏 | 雾青 `#A3C1BD`、浅湖蓝 `#9ABBD4` |
| 秋 | 暖咖、赭米色 |
| 冬 | 灰蓝、炭灰奶白 |

### 几何构成风

| 季节 | 底色 + 跳色 + 块面色 |
|------|---------------------|
| 春 | 冷灰底 + 嫩绿跳色 + 黑色块 |
| 夏 | 冷灰底 + 陶土橘 `#C97B5A` + 黑色块 |
| 秋 | 暖灰底 + 赭石跳色 + 深褐块 |
| 冬 | 银灰底 + 冰蓝跳色 + 炭黑块 |

| 立冬、小雪、大雪、冬至、小寒、大寒 | 冬 | 极素画册风、静默人文风、晨光纸艺风 |
