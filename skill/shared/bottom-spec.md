# 全局底部规范（三十五套统一）

以下规范适用于所有三十五套模板，不随风格变化。用户在生成任何海报时，底部联系信息区域必须严格遵守。

## 规范明细

| 规范项 | 标准 | 说明 |
|--------|------|------|
| 图标 | 无（纯文字） | 禁止任何 emoji、线性图标、符号前缀 |
| 字体大小 | 小 | 约为主标题字号的 1/4 至 1/3 |
| 行距 | 紧凑（约 1.1-1.2 倍） | 三行文字紧凑排列，视觉为一组信息块 |
| 二维码尺寸 | 缩小（约 15-18% 区域宽度） | 不喧宾夺主，保持谦逊 |
| 二维码下方文字 | "扫码了解更多" | 小字号，与联系信息同级 |
| 背景边框 | 无 | 联系信息区域无底色、无边框、无分隔线包裹 |

## 联系信息格式

```
地址：[企业地址]
电话：[企业电话]
邮箱：[企业邮箱]
```

- 三行纯文字，左对齐
- 无前缀图标、无项目符号
- 字色与各模板的文字辅助色一致

## 随机占位信息

若用户未提供企业联系信息，系统将根据 `company-config.md` 中的词库**随机生成**一套虚拟企业信息（公司名、地址、电话、邮箱均为随机组合，每次不同）。

示例输出（每次随机）：
```
地址：杭州市数字谷7栋
电话：0571-86347291
邮箱：hello@nexusdynamics.tech
```
