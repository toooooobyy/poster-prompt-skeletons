## 资源文件

LOGO 与二维码图像文件**不随仓库分发**，由使用方自行提供；各模板 Prompt 中仅以文字描述其位置、比例与样式（如 "A small LOGO mark"、"1:1 QR code placeholder"）。

## 使用规范

### LOGO 使用
- 按原比例缩放（宽高比约 1:1.2，竖版）
- 禁止拉伸变形
- 最小宽度不低于 120px 以保证文字可读
- 保持透明背景
- 风格：左上角竖排布局（LOGO 纵栏）

### 二维码使用
- 按原比例缩放（1:1 正方形）
- 禁止拉伸变形
- 尺寸约占海报区域宽度的 15-18%
- 下方标注"扫码了解更多"

### 联系信息格式
```
地址：{企业地址}
电话：{企业电话}
邮箱：{企业邮箱}
```
- 三行纯文字，左对齐
- 无前缀图标、无项目符号
- 行距紧凑（约 1.1-1.2 倍）
- 字体大小约为主标题字号的 1/4 至 1/3
