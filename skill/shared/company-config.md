# 企业信息配置（随机生成）

> 每次生成海报时，若用户未提供企业信息，系统将从以下词库中**随机组合**生成一套虚拟企业信息，确保每次输出不重复。生成的信息仅用于占位演示，非真实企业。

## 随机生成规则

## 使用规范

### LOGO 使用
- 按原比例缩放（宽高比约 1:1.2，竖版）
- 禁止拉伸变形
- 最小宽度不低于 120px 以保证文字可读
- 保持透明背景
- 风格：左上角竖排布局（LOGO 纵栏）

### 二维码使用
- 按原比例缩放（1:1 正方形）
- 禁止拉伸变形
- 尺寸约占海报区域宽度的 15-18%
- 下方标注"扫码了解更多"

### 联系信息格式
```
地址：{随机地址}
电话：{随机电话}
邮箱：{随机邮箱}
```
- 三行纯文字，左对齐
- 无前缀图标、无项目符号
- 行距紧凑（约 1.1-1.2 倍）
- 字体大小约为主标题字号的 1/4 至 1/3
