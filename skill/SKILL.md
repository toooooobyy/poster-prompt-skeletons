# 企业品牌日历海报生成 Skill

> 9:16 竖版企业日签海报专属设计系统，内置 35 套风格模板（7 大类别），固定版式 + 动态素材 + 风格标签矩阵，一键调用。

---

## 一、Skill 概述

本 Skill 是一套**固定版式企业品牌日历海报生成系统**，严格锁定"七层架构"方法论，内置 35 套独立风格模板，覆盖七大类别。用户仅需提供 5 个变量并指定风格代号，即可生成符合规范的 9:16 竖版海报。

**核心原则：**
- 版式骨架固定，仅替换动态素材
- 每套模板有独立的视觉风格锁死规则
- 底部联系信息规范已全局统一
- 每套模板附带四维风格标签，支持按需筛选
- 生成前必须执行六项输出自检

---

## 二、七层架构（通用方法论）

所有模板共享以下七层架构骨架：

### 第一层 · 身份定位
每套模板有独立的身份定位描述，定义其设计语言与适用场景。

### 第二层 · 刚性版式骨架
9:16 竖版画布，六大固定区块：
1. LOGO 区
2. 日期/星期区
3. 主视觉区（唯一可替换）
4. 主标题 + 副标题区
5. 联系信息区
6. 二维码区

**版式禁令：** 禁止随意移动六大区块顺序；禁止删减或增加区块；所有元素预留安全边距。

### 第三层 · 视觉风格锁死
每套模板独立定义：底色质感、色彩策略、字体层级、质感处理、四季色系规则。

### 第四层 · 文案规范
- 主标题 4-8 字
- 副标题单行短句 12-22 字
- 风格随模板气质调整，不硬推销

### 第五层 · 用户输入变量
用户仅需提供：
```
【时间标签】【主标题】【副标题】【主视觉画面描述】【季节色系】
```

### 第六层 · 输出自检
每套模板有专属自检清单（6 项），生成前必须逐项核对。

### 第七层 · 风格标签
每套模板附带四维风格标签，用于分类导航与按需筛选：

| 维度 | 可选值 |
|------|--------|
| 色温 | 暖调 / 冷调 / 中性 |
| 饱和度 | 高饱和 / 中饱和 / 低饱和 / 灰调 |
| 视觉类型 | 插画 / 摄影 / 3D / 几何 / 水墨 / 拼贴 |
| 适用场景 | 节气 / 商务 / 节日 / 日常 / 科技 / 文化 |

> 部分模板另含**第八层 · 风格变体**，共享版式骨架但微调视觉参数（如几何构成风含包豪斯原色变体、瑞士网格变体；新中式水墨风含写意笔触变体）。

## 六、工作流程

### 6.1 接收指令
用户指令格式：
```
用【风格代号】生成
【时间标签】【主标题】【副标题】【主视觉画面描述】【季节色系】
```

也支持按标签筛选：
```
给我一个暖调低饱和的节气海报
```
（系统根据风格标签矩阵自动筛选匹配模板）

### 6.2 执行步骤
1. 识别风格代号或解析标签筛选条件，加载对应模板规范（见 `templates/` 目录）
2. 解析用户变量
3. 若用户未提供变量，使用当前日期自动填充
4. 构建图片生成 prompt（严格遵循模板规范 + 全局底部规范）
5. 生成图片
6. 执行六项输出自检
7. 返回结果与文件链接

### 6.3 变量缺失时的默认值
| 变量 | 默认值 |
|------|--------|
| 时间标签 | 当前日期（系统时间） |
| 主标题 | 根据主题/节气自动生成 |
| 副标题 | 根据主题自动生成 |
| 主视觉画面描述 | 根据季节色系自动匹配 |
| 季节气系 | 根据当前月份自动判断 |

### 6.4 季节自动判断
| 月份 | 季节 |
|------|------|
| 3-5 月 | 春 |
| 6-8 月 | 夏 |
| 9-11 月 | 秋 |
| 12-2 月 | 冬 |

## 九、企业信息配置（随机生成）

若用户未提供企业信息，系统将从 `shared/company-config.md` 的词库中**随机生成**一套虚拟企业信息，每次生成结果不同。详细词库见 `shared/company-config.md`。

### 随机生成字段

| 字段 | 生成方式 |
|------|---------|
| 公司全称 | 前缀词库 + 行业词库 + 后缀词库（如：`星辰传媒有限公司`） |
| 公司简称 | 前缀词库中的一项（如：`星辰`） |
| 英文名 | 英文词1 + 英文词2，全大写（如：`NEXUS DYNAMICS`） |
| 地址 | 城市词库 + 楼宇词库 + 随机门栋号（如：`杭州市数字谷7栋`） |
| 电话 | 随机区号 + 随机7位数字（如：`0571-86347291`） |
| 邮箱 | `hello@` + 英文名小写 + 随机域名（如：`hello@nexusdynamics.tech`） |

### 资源文件

| 资源 | 路径 | 缩放规则 |
|------|------|---------|
| LOGO | `./assets/logo.png` | 原比例缩放（约 1:1.2 竖版），禁止拉伸变形 |
| 二维码 | `./assets/qrcode.jpg` | 原比例缩放（1:1 正方形），占区域宽度 15-18% |

### 底部联系信息模板（每次随机）
```
地址：{随机地址}
电话：{随机电话}
邮箱：{随机邮箱}
```

## 十、质量保证

每张海报生成后，必须执行对应模板的六项自检。若任一项未通过，必须重绘。

通用自检基准：
1. LOGO、二维码位置大小未变化
2. 底部信息无色块边框、无图标
3. 无杂乱装饰线条
4. 画风与模板规范一致
5. 文字未遮挡核心画面
6. 色彩饱和度符合模板要求
